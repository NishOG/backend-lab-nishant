3. Install Express (already done for this project):

   ```bash
   npm install express
   ```

4. Start the basic Node.js HTTP server:

   ```bash
   npm run start:http
   ```

   Open `http://localhost:3000/` to see `Hello`. Stop this server with `Ctrl+C` before starting the Express server because both use port 3000.

5. Start the Express server:

   ```bash
   npm start
   ```

   The server runs at `http://localhost:3000`. Stop it with `Ctrl+C` when finished.

   **Script note:** `npm start` is shorthand for `npm run start`; both run the same script. Therefore, the basic HTTP server uses the separate `start:http` script.

### 5. Implementation

- `http-server.js` uses Node.js's built-in `http` module to return `Hello` with status 200 and a plain-text content type.
- `server.js` creates an Express application and listens on port 3000.
- The application defines GET routes for `/`, `/about`, and `/time`.
- `/about` returns the student's name and section as JSON.
- `/time` returns the current date and time using `new Date()`.
- A final middleware handles unmatched paths with status 404 and the message `404 - Route not found.`
- A small middleware logs each request's method, URL, and final response status code in the terminal.

### 6. API Endpoints

| Method | Endpoint | Description | Expected Status |
|---|---|---|---:|
| GET | `/` | Welcome message | 200 |
| GET | `/about` | Returns student details in JSON | 200 |
| GET | `/time` | Returns current date and time | 200 |
| GET | `/unknown` | Handles unknown paths | 404 |
